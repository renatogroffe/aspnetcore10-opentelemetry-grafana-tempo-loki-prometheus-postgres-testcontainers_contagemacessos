# aspnetcore10-opentelemetry-grafana-tempo-loki-prometheus-postgres-testcontainers_contagemacessos
Exemplo de uso de OpenTelemetry + Grafana + Tempo (trace) + Loki (logs) + Prometheus (métricas) em uma API REST de contagem de acessos baseada em .NET 10 + ASP.NET Core e que utiliza uma base de dados PostgreSQL + Testcontainers. Inclui um script do Docker Compose para criação do ambiente de testes.
